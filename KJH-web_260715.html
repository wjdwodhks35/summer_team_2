시그니처 요소 — 시간 스택 바

결과 패널의 "시간 스택 바"가 이 서비스의 핵심 차별점이에요. 추천 출발시간이 기본 이동·대기·혼잡도·날씨·교통·목적·개인 여유 중 무엇으로 구성됐는지 색상 막대로 보여줘서, "왜 이 시간을 추천했는지" 설명하는 발표 포인트로 그대로 쓸 수 있습니다.

TMAP 기반 API 6개, 화면별 자리 배치

· 대중교통 요약정보 → 결과 카드의 이동시간/환승 정보
· 다중 경유지 안내 → 검색 폼의 "+ 경유지 추가"
· 진입역 기준 칸 혼잡도 → 세부정보 패널의 칸별 혼잡도 그래프
· 버스정류소정보(GPS, data.go.kr) → 지도 좌하단 "내 주변 정류장" 버튼
· 긴급재난문자(data.go.kr) → 화면 상단 안전안내문자 배너
· 기상청 단기예보(data.go.kr) → 지도 좌하단 날씨 위젯
대중교통 요약정보·칸 혼잡도는 appKey가 필요한 유료/무료체험 상품이라 브라우저에서 직접 부르면 안 되고, Spring Boot 백엔드가 대신 호출해서 우리 서버 API로 감싸줘야 해요.

TMAP 지도 API — 이미 연동되어 있어요

이 파일의 <head>에 실제 TMAP 지도 API v2 스크립트와 초기화 코드가 이미 들어있습니다. 다음 순서로 진행하면 목업 대신 진짜 지도가 떠요:
1. openapi.sk.com에서 회원가입 → 애플리케이션 등록 → TMAP 상품 추가 후 appKey 발급
2. <head> 안의 YOUR_TMAP_APP_KEY를 발급받은 값으로 교체
3. 이 파일을 웹 서버(또는 localhost)로 열기
appKey가 없거나 잘못됐으면 화면 좌상단에 안내 메시지가 뜨고 지금 보시는 목업 지도가 계속 표시됩니다. Claude 미리보기 화면에서는 스크립트 로드 자체가 제한되어 있어 항상 목업으로 보여요 — 다운로드해서 직접 열어보셔야 실제 지도를 확인할 수 있습니다.
